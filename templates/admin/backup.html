Restore from a backup

Warning: restoring replaces ALL current data (pages, products, enquiries, users) with the backup. A safety copy of the current data is saved automatically in the backups folder first. You will be logged out afterwards.

Manual restore (if the admin panel is not reachable)

  1. Stop the website application.
  2. Unzip the backup file.
  3. Copy proteinveda.db into the website folder (replace the existing one).
  4. Copy all files from the zip's uploads/ folder into static/uploads/.
  5. Start the website application again.

Automatic daily backups

On your server, schedule python backup.py to run daily (cron). It saves a zip in the backups/ folder and keeps the latest 14. See README.md.
